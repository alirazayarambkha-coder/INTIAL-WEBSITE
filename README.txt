CHEEZI UP — Photo folder
=========================

Put your real food photos in THIS folder, using the exact filenames
below (all lowercase, .jpg). The website will pick them up automatically
— no code changes needed.

If a file is missing, that item just shows the built-in illustrated
placeholder instead of a broken image, so the site never looks empty.

TIPS
----
- Square or landscape photos work best (roughly 800x600px or larger).
- Keep each file under ~500KB so the site stays fast — export as JPG,
  not PNG, for photos.
- .jpg, .jpeg, .png or .webp all work — if you use a different
  extension, just update the "src" path for that item in index.html
  to match (e.g. .png instead of .jpg).
